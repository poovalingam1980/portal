CEO சிவகங்கை — வகுப்பாசிரியர் Android App (PWA + .APK) நிறுவல் வழிகாட்டி
========================================================================

பகுதி 1: உடனடி Android Mobile App (PWA — 2 நிமிடங்களில்)
-------------------------------------------------------
1. இந்த ZIP-இல் உள்ள கீழ்க்கண்ட 3 கோப்புகளை உங்கள் GitHub Pages
   (portal.ceosvg.in) முதன்மை கோப்புறையில் (root folder) பதிவேற்றவும்:
   - ct.html
   - manifest-ct.json
   - sw-ct.js
2. வகுப்பாசிரியர்கள் தங்கள் Android போனில் Chrome வழியாக
   https://portal.ceosvg.in/ct.html திறந்தவுடன்
   "📲 Android App ஆக நிறுவுக (Install App)" என்பதை அழுத்தினால்
   போதும் — Home Screen-இல் தனி App Icon உருவாகிவிடும்!

பகுதி 2: நேரடி CEOSVG_ClassTeacher.apk உருவாக்குவது எப்படி? (இலவசம்)
-------------------------------------------------------------------
1. இந்த ZIP-இல் உள்ள:
   - android-app/ (கோப்புறை)
   - .github/workflows/build-ct-apk.yml
   ஆகியவற்றை உங்கள் GitHub repository-இல் பதிவேற்றவும்.
2. GitHub -> "Actions" தாவலுக்குச் சென்று
   "Build CEO SVG Class Teacher Android APK" -> "Run workflow" கிளிக் செய்யவும்.
3. 3 நிமிடங்களில் CEOSVG_ClassTeacher.apk தானாக உருவாகி
   Artifacts பகுதியில் பதிவிறக்கத் தயாராக இருக்கும்!
4. அந்த .apk கோப்பை WhatsApp வழியாக அனைத்து வகுப்பாசிரியர்களுக்கும்
   பகிர்ந்து நேரடியாக Android போனில் நிறுவலாம்.
