  - பள்ளி முகப்பில் (`👥 4. ஆசிரியர் & பணியாளர் பதிவேடு`) மாறுதல் / பணி ஓய்வு காரணமாக பணியாளரை நீக்கக் கோரிக்கை விடுக்கவும், மாவட்ட நிர்வாகி முகப்பில் (`🗑️ 10. பணியாளர் நீக்கக் கோரிக்கைகள்`) அதனைப் பார்வையிட்டு ஒப்புதல் அளிக்கவும் (Approve / Reject & CSV Export) முழுமையான வசதி ஏற்படுத்தப்பட்டுள்ளது.
